# Ethical AI Website

This project is a simple HTML website about the ethical use of Artificial Intelligence (AI). The website explains what AI is, its benefits, risks, and why AI should be used responsibly.

## Topics Included

- Introduction to Artificial Intelligence
- Benefits of AI
- Risks and dangers of AI
- Ethical use of AI
- Responsible AI practices

## Technologies Used

- HTML

## Purpose of the Project

The purpose of this project was to improve web development skills while researching how Artificial Intelligence impacts society and why ethical AI is important.
